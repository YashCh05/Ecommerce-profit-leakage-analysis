# 🛒 E-Commerce Profit Leakage & Risk Intelligence Analysis

## 📌 Project Overview

This project analyzes profitability challenges in an e-commerce business despite strong revenue growth.  

While revenue was increasing, profit margins were unstable due to returns, discount strategies, payment behavior, and operational inefficiencies.

The objective was to identify **where profit leakage occurs** and provide actionable insights using:

- 🐍 Python (Data Cleaning, Feature Engineering, EDA)
- 🗄 MySQL (Business Query Analysis)
- 📊 Power BI (Executive Dashboard)

---

## 🎯 Business Problem

The company was experiencing:

- High return rate (~22%)
- Significant return-driven loss
- Margin erosion from discounts
- COD payment risk
- Operational inefficiencies (refund delays, shipping costs)

Key Question:

> If revenue is growing, why isn't profit growing proportionally?

This project builds a **Profit Leakage Intelligence System** to answer that.

---

## 🧠 Key Insights

### 💰 Financial Overview
- Total Revenue: ₹360M  
- Total Profit: ₹90M  
- Return Rate: 22%  
- Return Loss: ₹40M  
- Profit Margin: 25%  

Returns alone were eroding nearly half of potential profit.

---

### 📦 Product-Level Leakage
- Identified loss-making SKUs
- Detected high-return subcategories
- Measured discount impact on margins

---

### 👤 Customer Risk Detection
- Flagged serial returners (40%+ return rate)
- Identified customers generating negative lifetime profit

---

### 💳 Payment Behavior Analysis
- COD showed higher return risk
- Prepaid/UPI delivered stronger profitability

---

### 🚚 Operational Insights
- City-wise return loss distribution
- Refund delay impact on return behavior
- Shipping cost ratio analysis
